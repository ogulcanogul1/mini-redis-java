# Differential test scenarios against real Redis 7.0.15 (REDIS_REFERANS.md).
# Format:
#   --- <scenario name>           : flush DB and open a fresh TCP connection
#   SEND <frames> <escaped bytes> : send bytes and compare <frames> exact RESP replies
#   SEND_CLOSE <frames> <bytes>   : send bytes, compare <frames> replies, assert EOF on both servers
#   SEND_UNORDERED <escaped>      : send bytes and compare RESP array elements ignoring order
#
# Intentional differences (not run here; tested in unit/acceptance tests):
#   1. Requests containing NUL (\0): Redis uses C strings in inline/error paths; we stay binary-safe.
#   2. KEYS [\x01-\x80]: Redis compares ranges with signed char on x86; we compare unsigned bytes.

SEND 1 *2\r\n$3\r\nGET\r\n$7\r\nmissing\r\n
SEND 1 *1\r\n$6\r\nDBSIZE\r\n
